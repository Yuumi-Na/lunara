# LUNARA — ร้านกำไลหินมงคล

เว็บร้านค้าออนไลน์สำหรับเลือกซื้อกำไลหินมงคล พัฒนาด้วย React, Vite, Express และ SQLite รองรับการเข้าสู่ระบบด้วย Google, หน้าจัดการร้านค้า, รีวิวจากผู้ซื้อจริง และภาษาไทย/อังกฤษ
- เว็บไซต์: https://lunara-rw6h.onrender.com

## ความสามารถ

- ดู ค้นหา และเลือกซื้อสินค้า พร้อมเลือกขนาดและจำนวน
- ตะกร้าสินค้าและรายการสินค้าที่ชอบ (Wishlist)
- เข้าสู่ระบบด้วย Google เพื่อสั่งซื้อและดูประวัติคำสั่งซื้อ
- ระบบโปรโมชั่นและรหัสส่วนลดที่ตรวจสอบโดยเซิร์ฟเวอร์
- รีวิวสินค้าได้เมื่อซื้อสินค้านั้นแล้ว และติดป้ายผู้ซื้อจริง
- หลังร้านสำหรับจัดการสินค้า คำสั่งซื้อ โปรโมชั่น ลูกค้า และรูปภาพ
- ตั้งผู้ดูแลได้ด้วยอีเมล Google หรือบัญชีผู้ดูแลแบบชื่อผู้ใช้/รหัสผ่าน
- สลับภาษาไทย/อังกฤษ และธีมสว่าง/มืด

## สิ่งที่ต้องมี

- Node.js เวอร์ชัน 22.5 ขึ้นไป (ใช้ SQLite ที่มากับ Node.js)
- npm
- Google OAuth Client ID สำหรับเปิดใช้ Google Sign-In

## ติดตั้งและเริ่มใช้งานในเครื่อง

1. เตรียมไฟล์โปรเจกต์ไว้ในเครื่องโดยเลือกทำวิธีใดวิธีหนึ่ง:

   - **ดาวน์โหลดจาก GitHub:** เปิดหน้า repository เลือก **Code → Download ZIP** แล้วแตกไฟล์ ZIP ไว้ในเครื่อง
   - **ใช้ Git:** เปิด PowerShell ในตำแหน่งที่จะเก็บโปรเจกต์ แล้วรันคำสั่ง โดยแทน `<URL-repository>` ด้วย URL ของ repository:

   ```powershell
   git clone https://github.com/Yuumi-Na/lunara.git
   cd lunara
   ```



2. ติดตั้ง dependencies:

   ```bash
   npm install
   ```

3. สร้างไฟล์ตั้งค่าส่วนตัว `.env.local` จากไฟล์ตัวอย่าง `.env.example` โดยเปิด Terminal ที่โฟลเดอร์โปรเจกต์แล้วรัน:

   ```powershell
   Copy-Item .env.example .env.local
   ```


4. เปิดไฟล์ `.env.local` ด้วย VS Code หรือโปรแกรมแก้ไขข้อความ แล้วแทนค่าตัวอย่างด้วยค่าจริง:

   ```env
   GOOGLE_CLIENT_ID="your_client_id.apps.googleusercontent.com"
   ADMIN_EMAILS="admin@example.com"
   SESSION_SECRET="replace-with-a-long-random-secret"
   ```

   - สร้าง `GOOGLE_CLIENT_ID` ใน Google Cloud Console ที่ [APIs & Services → Credentials](https://console.cloud.google.com/apis/credentials) โดยเลือก OAuth Client ID ประเภท **Web application**
   - เพิ่ม `http://localhost:3000` ใน **Authorized JavaScript origins**
   - `ADMIN_EMAILS` ใส่อีเมล Google ของผู้ดูแล หากมีหลายคนให้คั่นด้วย comma
   - สร้าง `SESSION_SECRET` แบบสุ่มที่คาดเดายาก เช่นใช้คำสั่ง `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"` แล้วนำผลลัพธ์ไปใส่ในไฟล์
   - อย่าใส่รหัสผ่านจริงหรือ secret ลง Git และอย่าเผยแพร่ `.env.local`

5. เริ่มเซิร์ฟเวอร์สำหรับพัฒนา:

   ```bash
   npm run dev
   ```

6. เปิด [http://localhost:3000](http://localhost:3000)

หยุดเซิร์ฟเวอร์ด้วย `Ctrl+C` เมื่อใช้งานเสร็จ

## วิธีใช้งาน

### ลูกค้า

#### เลือกสินค้าและค้นหากำไล

- เลือกดูสินค้าทั้งหมด พร้อมค้นหาจากชื่อสินค้า ชื่อหิน หรือคำอธิบายได้ทั้งภาษาไทยและภาษาอังกฤษ
- กรองสินค้าตามความตั้งใจ สี สไตล์ และช่วงราคา รวมถึงเรียงตามสินค้าแนะนำ ความนิยม หรือราคา
- ใช้หน้า **ค้นหากำไลที่เหมาะกับคุณ** เลือกความตั้งใจ สี สไตล์ และงบประมาณ เพื่อดูสินค้าแนะนำพร้อมคะแนนความตรงกับตัวเลือก
- เปิดดูรายละเอียดสินค้า ภาพหลายมุม ราคา ขนาด รอบข้อมือ รายละเอียดหิน ความเชื่อ และคำแนะนำการดูแล (เมื่อมีข้อมูล)
- เปิดคู่มือหินมงคลเพื่อค้นหาชื่อหินหรือเลือกดูตามหมวดหมู่ แล้วไปยังสินค้าที่เกี่ยวข้อง

#### ออกแบบและเพิ่มสินค้าที่สนใจ

- สร้างกำไลแบบกำหนดเอง โดยเลือกหิน ขนาดเม็ดหิน ขนาดข้อมือ และจี้ จากนั้นระบบแสดงราคาและเพิ่มแบบที่ออกแบบลงตะกร้า
- เพิ่มหรือนำสินค้าออกจาก Wishlist ได้โดยไม่ต้องเข้าสู่ระบบ
- เพิ่มสินค้าลงตะกร้า ปรับจำนวนหรือลบสินค้า และดูยอดรวมกับความคืบหน้าสู่การจัดส่งฟรีได้

#### สั่งซื้อและติดตามรายการ

1. เข้าสู่ระบบด้วย Google ก่อนชำระเงิน
2. กรอกชื่อ เบอร์โทรศัพท์ และที่อยู่จัดส่ง
3. ตรวจสอบยอดและส่วนลด ระบบคำนวณราคาและตรวจสอบโค้ดโปรโมชั่นจากเซิร์ฟเวอร์
4. เลือกวิธีชำระเงินที่หน้า Checkout: PromptPay, บัตรเครดิต หรือเก็บเงินปลายทาง (COD)
5. หลังส่งคำสั่งซื้อ ดูรหัสคำสั่งซื้อ ยอดชำระ และสถานะได้ที่หน้า `/account`
6. กรองประวัติคำสั่งซื้อตามสถานะ และติดตามความคืบหน้าตั้งแต่รับคำสั่งซื้อจนถึงจัดส่งสำเร็จ

บัญชีลูกค้าแสดงข้อมูลโปรไฟล์และระดับสมาชิก/สิทธิ์สมาชิกใหม่เมื่อมีสิทธิ์ดังกล่าว

#### รีวิวสินค้า

- รีวิวได้เมื่อเข้าสู่ระบบและเคยสั่งซื้อสินค้านั้น โดยคำสั่งซื้อที่ถูกยกเลิกไม่นับเป็นการซื้อที่ยืนยันแล้ว
- หนึ่งบัญชีมีรีวิวได้หนึ่งรายการต่อสินค้า และส่งรีวิวใหม่เพื่อแก้ไขรีวิวเดิมได้
- ชื่อและรูปผู้รีวิวอ้างอิงจากบัญชีที่เข้าสู่ระบบ รีวิวจากผู้ซื้อจริงจะแสดงป้ายยืนยัน และสามารถดูคำตอบจากร้านใต้รีวิวได้

### ผู้ดูแลร้าน

- เข้า `/admin` แล้วเข้าสู่ระบบด้วยบัญชี Google ที่อยู่ใน `ADMIN_EMAILS` หรือบัญชีผู้ดูแลแบบชื่อผู้ใช้/รหัสผ่าน
- จัดการสินค้า คำสั่งซื้อ โปรโมชั่น ลูกค้า และรูปภาพได้จากเมนูในหน้าหลังร้าน
- รูปที่อัปโหลดรองรับ JPG, PNG และ WEBP โดยจำกัดขนาดตามที่เซิร์ฟเวอร์กำหนด
- การเข้าสู่ระบบด้วยรหัสผ่านมีไว้สำหรับผู้ดูแลเท่านั้น ลูกค้าทั่วไปใช้ Google

ตั้งค่าหรือเปลี่ยนบัญชีผู้ดูแลแบบชื่อผู้ใช้/รหัสผ่านด้วยคำสั่ง:

```bash
npm run admin:password -- <username> <password>
```

ชื่อผู้ใช้ต้องยาว 3–32 ตัวอักษร (ตัวอักษรอังกฤษ ตัวเลข `.`, `_`, `-`) และรหัสผ่านต้องยาวอย่างน้อย 8 ตัวอักษร คำสั่งจะบันทึก hash ลง `.env.local` ไม่ได้บันทึกรหัสผ่านตรง ๆ จากนั้นรีสตาร์ทเซิร์ฟเวอร์ หากใส่รหัสผิดครบ 5 ครั้ง ระบบจะพักการเข้าสู่ระบบจาก IP นั้น 15 นาที
